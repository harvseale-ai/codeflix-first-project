About Codeflix details

What is Codeflix?

Codeflix is a learning dashboard designed to help beginner developers keep their coding resources in one place. It uses a Netflix-style content page for discovery, a Markdown reader for notes, and a full-screen workspace for embedded tools like Miro, Padlet, and Figma.

Main features

  • Browse coding resources from a Netflix-style homepage.
  • Open Markdown cheat sheets for HTML, CSS, JavaScript, and SQL.
  • Use full-page embedded tools for planning and project work.
  • Submit reusable HTML, CSS, and JavaScript snippets.
  • Keep learning materials organised by topic.

Who is it for?

Codeflix is for coding students, beginner developers, and self-taught learners who want a clean workspace for notes, resources, examples, and project planning.

Use case

A learner can open a CSS cheat sheet, watch a tutorial, save a snippet, and access a project planning board without leaving the workspace.

How to use Codeflix

  1. Start from the homepage to browse coding topics, tutorials, and learning resources.
  2. Open Markdown cheat sheets and notes from the sidebar navigation to study HTML, CSS, JavaScript, and SQL topics.
  3. Save reusable code examples and project ideas in the snippets page to build your own coding library.
  4. Use the workspace page for planning, whiteboarding, scheduling, and project organisation with embedded tools.
  5. Move between notes, videos, snippets, and workspace tools without leaving the learning environment.
